Case Study 01

Local Café Website Redesign

A complete digital refresh designed to make a neighborhood café easier to discover, easier to browse, and more professional online.

Situation The café’s old website was difficult to use on mobile devices and did not clearly present opening hours, menu highlights, or the brand personality.
Task Create a modern, responsive website that improves customer access to key information and strengthens trust in the brand.
Action We redesigned the page structure, improved navigation, introduced clearer visual hierarchy, and refreshed colors and typography for a cleaner customer experience.
Result: The new website delivered a stronger first impression, improved mobile usability, and made important information much faster to find.

Smarter Booking Flow

Case Study 02

Appointment Booking Automation

A workflow improvement project focused on reducing scheduling confusion and helping a small service business manage appointments more efficiently.

Situation Appointments were being handled manually through calls and spreadsheets, which led to double-bookings, inconsistent records, and unnecessary admin effort.
Task Develop a clear digital process that organizes bookings, improves visibility, and reduces time spent on repetitive scheduling tasks.
Action We mapped the booking journey, structured appointment data more clearly, and designed a workflow that made incoming requests easier to track and manage.
Result: The improved workflow reduced scheduling errors, created better internal organization, and saved several hours of manual work each week.
Case Study 03

Student Event Registration Page

A focused landing page project created to make event sign-ups easier, more attractive, and more organized for both participants and organizers.

Situation A student organization needed a more professional way to present an event and manage registrations without relying on scattered communication.
Task Build a clear, visually engaging registration page that encourages participation and simplifies information collection.
Action We created a dedicated landing page, structured the event information more effectively, and designed a clean registration flow that reduced friction for users.
Result: The final page improved communication, supported a smoother sign-up experience, and elevated the overall presentation of the event.
★

Clearer Event Experience

A simple, attractive sign-up flow with stronger presentation and better structure.
